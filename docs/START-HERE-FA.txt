راهنمای راه‌اندازی برنامه

DisRoute

این برنامه برای ویندوز ۶۴ بیتی ساخته شده است.


۱) آماده‌کردن فایل‌ها

فایل دانلودشده فشرده است. ابتدا روی آن راست‌کلیک کنید و گزینهٔ «استخراج همه» را بزنید.

نام فایل دانلودی به این شکل است:

DisRoute-0.2.5-windows-x64.zip

برنامه را مستقیم از داخل فایل فشرده اجرا نکنید.


۲) نصب پیش‌نیازها

فایل نصب پیش‌نیاز که کنار برنامه قرار دارد را یک‌بار اجرا کنید:

ProxiFyre-2.6.1-win-x64-setup.exe

این فایل درایور زیر را نصب می‌کند:

Windows Packet Filter

اگر این درایور قبلاً نصب شده است، نیازی به نصب دوباره ندارید.

دو پیش‌نیاز مایکروسافت نیز باید روی ویندوز نصب باشند:

Microsoft Edge WebView2 Runtime
Microsoft Visual C++ Runtime x64


۳) اجرای برنامه

روی فایل زیر راست‌کلیک کنید:

DisRoute.exe

سپس این گزینه را بزنید:

Run as administrator

پوشهٔ زیر باید همیشه کنار فایل برنامه بماند:

engine


۴) اتصال دیسکورد

لینک اتصال خود را در کادر مربوط وارد کنید. ابتدای لینک باید به این شکل باشد:

vless://

سپس دکمهٔ سبزرنگ اتصال را بزنید.

اگر گزینهٔ ذخیره روشن باشد، دفعهٔ بعد نیازی به واردکردن دوبارهٔ لینک نیست.

اگر دیسکورد از قبل باز است، آن را کامل ببندید و دوباره اجرا کنید.

اگر پنجرهٔ دیسکورد باز نشد، دکمهٔ زیر را داخل برنامه بزنید:

Restart Discord

این کار فقط پردازش‌های گیرکردهٔ دیسکورد را دوباره راه‌اندازی می‌کند و اتصال برنامه روشن می‌ماند.


۵) تماس صوتی

برای کارکردن تماس صوتی، سرور باید از یکی از روش‌های زیر پشتیبانی کند:

UDP
XUDP

برقرارشدن اتصال برنامه به‌تنهایی به معنی درست‌بودن تنظیمات تماس صوتی سرور نیست.


۶) فرستادن برنامه به بخش اعلان‌های ویندوز

دکمهٔ مربوط به این کار در بالای برنامه قرار دارد:

Minimize to tray

با زدن این دکمه، پنجره بسته می‌شود اما اتصال فعال می‌ماند. برای بازکردن دوباره، در بخش اعلان‌های نوار وظیفه روی آیکون برنامه کلیک کنید.

برای بستن کامل برنامه، روی همان آیکون راست‌کلیک کنید و گزینهٔ «قطع اتصال و خروج» را بزنید.


۷) ذخیره و حذف کانفیگ

کانفیگ با حساب ویندوز رمزگذاری می‌شود و در مسیر زیر قرار می‌گیرد:

%LOCALAPPDATA%\app.disroute.desktop\profile.dpapi

برای پاک‌کردن آن، دکمهٔ «حذف کانفیگ ذخیره‌شده» را داخل برنامه بزنید.


۸) نکات مهم

این نسخه آزمایشی است و امضای دیجیتال ندارد.

اگر ویندوز هشدار امنیتی نشان داد، نام فایل و مقدار بررسی آن را با اطلاعات صفحهٔ انتشار نسخه مقایسه کنید. نوع مقدار بررسی فایل:

SHA256

این برنامه فقط پردازش‌های دیسکورد را وارد مسیر پروکسی می‌کند. تنظیمات پروکسی یا نام‌سرور کل ویندوز تغییر نمی‌کند. مصرف پهنای باند مشترک همچنان ممکن است روی بازی‌ها اثر بگذارد.
