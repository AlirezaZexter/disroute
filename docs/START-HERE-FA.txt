راهنمای شروع DisRoute
=====================

DisRoute برای ویندوز ۶۴ بیتی ساخته شده است.
این برنامه فقط ترافیک Discord را از پروکسی عبور می‌دهد.
بازی‌ها، مرورگر و برنامه‌های دیگر از اینترنت عادی استفاده می‌کنند.


۱. دانلود برنامه
----------------

صفحهٔ Releases پروژه را در GitHub باز کنید.
از بخش Assets، فایل نصب ویندوز را دانلود کنید.

نام فایل نصب نسخهٔ فعلی:

DisRoute-0.5.0-windows-x64-setup.exe

فایل‌های Source code برنامهٔ آمادهٔ نصب نیستند.


۲. نصب پیش‌نیاز شبکه
-------------------

برای جداکردن مسیر Discord، نصب Windows Packet Filter لازم است.

بستهٔ Portable مربوط به ProxiFyre را از همان صفحهٔ انتشار بگیرید.
آن را کامل استخراج کنید.
سپس فایل زیر را فقط یک‌بار اجرا کنید:

ProxiFyre-2.6.1-win-x64-setup.exe

اگر قبلاً ProxiFyre را نصب کرده‌اید، این مرحله لازم نیست.

دو پیش‌نیاز مایکروسافت نیز باید نصب باشند:

Microsoft Edge WebView2 Runtime
Microsoft Visual C++ Runtime x64


۳. نصب و اجرای برنامه
--------------------

فایل نصب DisRoute را اجرا کنید و مراحل نصب را به پایان برسانید.
موتورهای شبکه همراه برنامه نصب می‌شوند.
لازم نیست پوشهٔ engine را دستی جابه‌جا کنید.

روی میان‌بُر DisRoute راست‌کلیک کنید.
سپس این گزینه را بزنید:

Run as administrator

این دسترسی برای ساخت قانون Firewall و مسیریابی پردازش Discord لازم است.


۴. اتصال با کانفیگ شخصی
----------------------

بخش «کانفیگ شخصی» را باز کنید.
لینک اتصال خود را وارد کنید.

نوع‌های پشتیبانی‌شده:

vless://
vmess://
trojan://
ss://

دکمهٔ «اتصال Discord» را بزنید.

اگر گزینهٔ ذخیره روشن باشد، کانفیگ با حساب ویندوز رمزگذاری می‌شود.
در اجرای بعدی لازم نیست لینک را دوباره وارد کنید.


۵. اتصال سریع رایگان
-------------------

اگر کانفیگ شخصی ندارید، بخش «اتصال سریع رایگان» را باز کنید.
هشدار سرورهای شخص ثالث را کامل بخوانید و تأیید کنید.

برنامه منابع فعال را دریافت می‌کند.
کانفیگ‌های نامعتبر را کنار می‌گذارد.
سپس اتصال واقعی گزینه‌ها را آزمایش و بهترین گزینهٔ فعلی را انتخاب می‌کند.

این سرورها متعلق به DisRoute نیستند.
نتیجهٔ آزمایش فقط وضعیت همان لحظه را نشان می‌دهد.
امنیت، حریم خصوصی، پایداری، تماس صوتی و استریم تضمین نمی‌شوند.


۶. بازکردن دوبارهٔ Discord
-------------------------

اگر وضعیت برنامه «متصل است» بود اما Discord وصل نشد، این دکمه را بزنید:

Restart Discord

این دکمه فقط Discord را می‌بندد و دوباره اجرا می‌کند.
اتصال DisRoute روشن می‌ماند.


۷. تماس صوتی و استریم
--------------------

وصل‌شدن پیام‌ها، سالم‌بودن تماس صوتی را ثابت نمی‌کند.
برای Voice و استریم، کانفیگ باید UDP و آپلود مناسب داشته باشد.

بعضی لینک‌های VLESS و VMess از یکی از حالت‌های زیر استفاده می‌کنند:

XUDP
packetaddr

اگر صدا وصل است اما استریم قطع‌ووصلی دارد، سرور نزدیک‌تری امتحان کنید.
مصرف هم‌زمان پهنای باند نیز می‌تواند پینگ بازی را بالا ببرد.


۸. فرستادن برنامه به کنار ساعت ویندوز
-------------------------------------

دکمهٔ زیر در بالای برنامه قرار دارد:

Minimize to system tray

با زدن آن، فقط پنجره بسته می‌شود و اتصال روشن می‌ماند.
برای بازکردن دوباره، روی آیکون DisRoute کنار ساعت ویندوز کلیک کنید.

برای خروج کامل، روی همان آیکون راست‌کلیک کنید.
سپس گزینهٔ «قطع اتصال و خروج» را بزنید.


۹. آپدیت برنامه
---------------

در بالای برنامه روی «بررسی آپدیت» بزنید.
اگر نسخهٔ جدیدی وجود داشته باشد، دکمهٔ «دانلود و نصب» نمایش داده می‌شود.

فایل آپدیت پس از دانلود، از نظر امضا بررسی می‌شود.
سپس اتصال Discord قطع، نسخهٔ جدید نصب و برنامه دوباره اجرا می‌شود.

آپدیت خودکار و بی‌صدا انجام نمی‌شود.

نسخه‌های قدیمی‌تر از 0.4.1 آپدیتر داخلی ندارند.
برای عبور از آن نسخه‌ها باید فایل نصب جدید را یک‌بار دستی اجرا کنید.


۱۰. حذف کانفیگ و داده‌های اتصال سریع
------------------------------------

برای حذف کانفیگ شخصی، این گزینه را داخل برنامه بزنید:

حذف کانفیگ ذخیره‌شده

برای حذف فهرست‌های دریافت‌شده و سابقهٔ آزمایش، این گزینه را بزنید:

پاک‌کردن کش و سابقه


۱۱. هشدار Windows SmartScreen
-----------------------------

آپدیت داخل برنامه با کلید اختصاصی DisRoute بررسی می‌شود.
فایل نصب هنوز امضای Authenticode ندارد.
به همین دلیل ممکن است Windows SmartScreen هنگام نصب هشدار نشان دهد.
