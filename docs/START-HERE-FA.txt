راهنمای شروع DisRoute
=====================

این نسخه برای ویندوز ۶۴ بیتی ساخته شده است.

نصب و اجرا
-----------

۱. فایل ZIP را کامل Extract کنید. برنامه را مستقیم از داخل ZIP اجرا نکنید.

۲. فایل نصب ProxiFyre را که داخل پوشه قرار دارد اجرا کنید. این فایل پیش‌نیاز Windows Packet Filter را نصب می‌کند. اگر قبلاً نصب شده است، لازم نیست دوباره آن را نصب کنید.

۳. Microsoft Edge WebView2 Runtime و Microsoft Visual C++ Runtime x64 باید روی ویندوز نصب باشند.

۴. روی DisRoute.exe راست‌کلیک کنید و Run as administrator را بزنید. پوشه engine باید کنار فایل برنامه بماند.

۵. لینک VLESS را وارد کنید و روی «اتصال Discord» بزنید. اگر گزینهٔ ذخیره روشن باشد، کانفیگ برای دفعهٔ بعد باقی می‌ماند.

۶. اگر Discord از قبل باز است، آن را کامل Quit کنید و دوباره باز کنید.

تماس صوتی
----------

برای تماس صوتی، سرور VLESS باید UDP یا XUDP را پشتیبانی کند. متصل‌شدن برنامه به‌تنهایی تضمین نمی‌کند که تنظیمات UDP سرور درست باشد.

Minimize to tray
----------------

با بستن پنجره یا زدن دکمه Minimize to tray، برنامه در System tray فعال می‌ماند. برای بازکردن دوباره، روی آیکون DisRoute در System tray کلیک کنید.

برای بستن کامل برنامه، روی آیکون DisRoute راست‌کلیک کنید و «قطع اتصال و خروج» را بزنید.

ذخیرهٔ کانفیگ
-------------

کانفیگ با حساب ویندوز رمزگذاری می‌شود و در این مسیر قرار می‌گیرد:

%LOCALAPPDATA%\app.disroute.desktop\profile.dpapi

برای پاک‌کردن آن، از گزینهٔ «حذف کانفیگ ذخیره‌شده» داخل برنامه استفاده کنید.

نکته
-----

این نسخه هنوز Preview است و امضای دیجیتال ندارد. اگر Windows SmartScreen هشدار داد، نام فایل و هش SHA256 موجود در صفحهٔ Release را بررسی کنید.

DisRoute فقط پردازش‌های Discord را وارد مسیر پروکسی می‌کند و تنظیمات Proxy یا DNS کل ویندوز را تغییر نمی‌دهد. بااین‌حال، مصرف پهنای باند مشترک ممکن است روی بازی یا برنامه‌های دیگر اثر بگذارد.
