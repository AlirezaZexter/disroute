راهنمای نصب و استفاده از DisRoute

این برنامه برای ویندوز ۶۴ بیتی ساخته شده است.


۱) دانلود برنامه

صفحهٔ Releases را در GitHub باز کنید و فایل نصبی ویندوز را بگیرید.

نام فایل نصبی شبیه این است:

DisRoute-0.4.0-windows-x64-setup.exe

فایل‌های Source code خود GitHub برنامهٔ آمادهٔ اجرا نیستند.


۲) نصب پیش‌نیاز شبکه

DisRoute برای مسیریابی جداگانهٔ Discord به Windows Packet Filter نیاز دارد.

اگر قبلاً بستهٔ ProxiFyre را نصب کرده‌اید، این مرحله را رد کنید. در غیر این صورت، بستهٔ Portable را از همان صفحهٔ انتشار بگیرید، آن را کامل استخراج کنید و این فایل را یک‌بار اجرا کنید:

ProxiFyre-2.6.1-win-x64-setup.exe

این دو پیش‌نیاز مایکروسافت هم باید روی ویندوز نصب باشند:

Microsoft Edge WebView2 Runtime
Microsoft Visual C++ Runtime x64


۳) نصب و اجرای DisRoute

فایل Setup را اجرا و نصب را کامل کنید. بعد روی میان‌بُر DisRoute راست‌کلیک کنید و گزینهٔ زیر را بزنید:

Run as administrator

فایل‌های موتور شبکه همراه برنامه نصب می‌شوند و دیگر لازم نیست پوشهٔ engine را دستی کنار برنامه نگه دارید.


۴) اتصال Discord

لینک اتصال خود را در برنامه وارد کنید. این چهار نوع لینک پشتیبانی می‌شوند:

vless://
vmess://
trojan://
ss://

دکمهٔ «اتصال Discord» را بزنید. اگر ذخیرهٔ کانفیگ روشن باشد، دفعهٔ بعد لازم نیست لینک را دوباره وارد کنید.

اگر پنجرهٔ Discord باز نشد، دکمهٔ زیر را داخل برنامه بزنید:

Restart Discord

این دکمه فقط Discord را دوباره اجرا می‌کند و اتصال DisRoute روشن می‌ماند.


۵) تماس صوتی و استریم

سرور و پروتکل انتخابی باید از UDP پشتیبانی کنند. وصل‌شدن پیام‌ها به‌تنهایی سالم‌بودن تماس صوتی را ثابت نمی‌کند.

لینک‌های VLESS و VMess می‌توانند یکی از حالت‌های زیر را برای انتقال بسته مشخص کنند:

XUDP
packetaddr

اگر تماس برقرار می‌شود اما استریم قطع‌ووصلی دارد، سروری نزدیک‌تر با آپلود و پشتیبانی UDP بهتر امتحان کنید.


۶) فرستادن برنامه به بخش اعلان‌های ویندوز

این دکمه در بالای برنامه قرار دارد:

Minimize to tray

با زدن آن، پنجره بسته می‌شود اما اتصال فعال می‌ماند. برای بازکردن دوباره، روی آیکون DisRoute در بخش اعلان‌های نوار وظیفه کلیک کنید.

برای خروج کامل، روی همان آیکون راست‌کلیک کنید و گزینهٔ «قطع اتصال و خروج» را بزنید.


۷) آپدیت برنامه

در بالای برنامه روی «بررسی آپدیت» بزنید. اگر نسخهٔ جدیدی منتشر شده باشد، شمارهٔ نسخه و دکمهٔ «دانلود و نصب» نمایش داده می‌شود.

DisRoute فایل را دانلود و امضای آن را بررسی می‌کند. بعد از پایان دانلود، اتصال Discord قطع می‌شود، نصب انجام می‌گیرد و برنامه دوباره اجرا می‌شود.

نسخه‌های قدیمی‌تر از 0.4.0 آپدیتر داخلی ندارند. برای رفتن از آن نسخه‌ها به 0.4.0 باید فایل Setup را یک‌بار دستی نصب کنید.


۸) ذخیره و حذف کانفیگ

کانفیگ با حساب ویندوز رمزگذاری می‌شود و در این مسیر قرار می‌گیرد:

%LOCALAPPDATA%\app.disroute.desktop\profile.dpapi

برای پاک‌کردنش، دکمهٔ «حذف کانفیگ ذخیره‌شده» را داخل برنامه بزنید.


۹) هشدار ویندوز

آپدیت‌های داخل برنامه با کلید اختصاصی DisRoute بررسی می‌شوند. فایل Setup هنوز امضای Authenticode ندارد؛ به همین دلیل ممکن است Windows SmartScreen موقع نصب هشدار نشان دهد.

DisRoute فقط پردازش‌های Discord را وارد مسیر پروکسی می‌کند. تنظیمات پروکسی یا نام‌سرور کل ویندوز تغییر نمی‌کند. بااین‌حال، مصرف مشترک پهنای باند ممکن است روی پینگ بازی اثر بگذارد.
