# راهنمای شروع DisRoute

این نسخه آزمایشی مخصوص ویندوز x64 است و با Discord ارتباط رسمی ندارد.

1. ZIP را کامل در یک پوشه جدا Extract کنید.
2. روی دستگاه جدید، نصب‌کننده رسمی ProxiFyre موجود در بسته را برای پیش‌نیازها اجرا کنید و مراحل آن را خودتان تأیید کنید. مجوز و پیش‌نیازهای Windows Packet Filter را بررسی کنید. اگر درایور قبلاً نصب شده نیازی به نصب مجدد نیست. سرویس یا برنامه مستقل ProxiFyre نباید هم‌زمان با DisRoute فعال باشد.
3. Microsoft Edge WebView2 Runtime و Visual C++ Runtime x64 باید نصب باشند؛ فقط از وب‌سایت رسمی Microsoft دریافت کنید.
4. DisRoute.exe را با Run as administrator اجرا کنید. پوشه engine را جابه‌جا نکنید.
5. کانفیگ VLESS خودتان را وارد کنید، گزینه «کانفیگ برای دفعات بعد ذخیره شود» را روشن بگذارید و اتصال را بزنید. برای ذخیره بدون اتصال هم دکمه «ذخیره تنظیمات» وجود دارد.
6. Discord را باز کنید. اگر از قبل باز بوده، کاملاً Quit و دوباره اجرا کنید. برای وویس، سرور VLESS باید UDP/XUDP را پشتیبانی کند.

## ذخیره و حریم خصوصی

کانفیگ با DPAPI ویندوز رمزگذاری و در `%LOCALAPPDATA%/app.disroute.desktop/profile.dpapi` ذخیره می‌شود. بازیابی به همان حساب ویندوز وابسته است؛ اجرای برنامه با حساب Administrator متفاوت، پروفایل جداگانه دارد. برای حذف، از دکمه حذف کانفیگ ذخیره‌شده استفاده کنید.

فایل موقت plaintext موردنیاز موتور در پوشه runtime داخل AppData است، نه داخل ZIP. توقف عادی آن را حذف می‌کند؛ بعد از crash ممکن است باقی بماند. این برنامه در برابر بدافزار دارای دسترسی به حساب یا Administrator محافظت کامل ایجاد نمی‌کند.

برای دوستان فقط ZIP اصلی نسخه را بفرستید؛ از پوشه استفاده‌شده، AppData، لاگ‌ها یا کانفیگ شخصی ZIP جدید نسازید. هر نفر لینک خودش را وارد می‌کند.

## محدودیت‌ها

دکمه «کنار ساعت» یا ضربدر پنجره، برنامه را مخفی می‌کند و اتصال فعال می‌ماند. برای بازکردن، آیکون DisRoute کنار ساعت را کلیک کنید. برای بستن کامل، روی آیکون راست‌کلیک و «قطع اتصال و خروج» را انتخاب کنید. دکمه مینیمایز عادی هم در نوار عنوان باقی است.

برنامه فعلاً امضای دیجیتال ندارد؛ هش را با فایل sha256 نسخه مقایسه کنید و هشدارهای امنیتی را بی‌بررسی رد نکنید. آماده‌بودن تونل تضمین تماس صوتی یا جلوگیری کامل از نشت نیست. تغییر DNS ویندوز یا VPN سراسری انجام نمی‌شود، اما مصرف پهنای باند مشترک همچنان می‌تواند روی بازی اثر بگذارد.
