# DisRoute `0.5.3`؛ لوگوی جدید و اتصال سریع‌تر

- لوگوی تأییدشده در برنامه، آیکون ویندوز و System tray قرار گرفته است.
- فهرست‌های ترکیه، فرانسه، امارات و یک فهرست با سابقهٔ پایداری از منابع عمومی فعلی اضافه شده‌اند.
- دریافت منابع هم‌زمان انجام می‌شود و اتصال دوباره، فهرست تازهٔ ذخیره‌شده را بی‌دلیل دانلود نمی‌کند.
- منابع کوچک‌تر هم سهمی از آزمایش دارند. نتیجهٔ تست‌های محلی برای دفعات بعد ذخیره می‌شود.
- پس از پیدا شدن چند گزینهٔ پایدار، آزمایش زودتر تمام می‌شود. رتبه‌بندی با زمان اتصال واقعی، نوسان، خطا و وضعیت UDP انجام می‌شود.
- حجم و سرعت دریافت آپدیت نمایش داده می‌شود و نمایش پیشرفت، رابط را به‌ازای هر تکهٔ دانلود دوباره رسم نمی‌کند.

آپدیتر همچنان فایل کامل نصب را دریافت می‌کند، نه فقط تغییرات نسخه. امضای بسته بررسی می‌شود. مسیریابی فقط برای Discord باقی مانده است.

آزمایش UDP به معنی تضمین کیفیت وویس یا استریم نیست. اتصال‌های عمومی ممکن است بعد از آزمایش هم قطع شوند.

## سابقهٔ نسخهٔ `0.5.2`

## تغییرات این نسخه

- بخش‌های رابط از هم جدا شده‌اند تا وضعیت اتصال، روش اتصال و مسیر ترافیک سریع‌تر دیده شوند.
- جابه‌جایی میان بخش‌ها و تغییر وضعیت‌ها با حرکت‌های کوتاه و کنترل‌شده انجام می‌شود و تنظیم کاهش حرکت ویندوز هم رعایت شده است.
- فونت فارسی وزیرمتن داخل برنامه قرار گرفته است؛ متن‌های ریز، فاصلهٔ خطوط و ترکیب نوشته‌های فارسی و انگلیسی خواناتر شده‌اند.
- راهنمای شروع داخل برنامه با روش نصب فعلی، اتصال شخصی، اتصال سریع، تماس صوتی، System tray و آپدیتر هماهنگ شده است.
- نمایش وضعیت ذخیره‌شدن کانفیگ و پیام‌های فرم واضح‌تر شده است.
- منطق اتصال، Xray، قوانین Firewall، Community Quick Connect و مسیریابی اختصاصی Discord نسبت به نسخهٔ 0.5.1 تغییری نکرده است.

## نصب و آپدیت

برای نصب جدید، فایل زیر را از بخش Assets همین Release دانلود کنید:

`DisRoute-0.5.2-windows-x64-setup.exe`

برنامه را با گزینهٔ `Run as administrator` اجرا کنید. اگر Windows Packet Filter از قبل نصب نیست، فایل Portable را استخراج کنید و `ProxiFyre-2.6.1-win-x64-setup.exe` را یک‌بار اجرا کنید.

کاربران نسخهٔ `0.4.1` و جدیدتر می‌توانند داخل DisRoute روی «بررسی آپدیت» بزنند و نسخهٔ جدید را مستقیم نصب کنند. نسخه‌های قدیمی‌تر باید فایل نصب فعلی را یک‌بار دستی اجرا کنند.

بستهٔ آپدیت داخل برنامه با امضای DisRoute بررسی می‌شود. خود فایل Setup هنوز امضای Authenticode ندارد و ممکن است Windows SmartScreen هنگام نصب هشدار نشان دهد.

## محدودیت اتصال سریع

سرورهای اتصال سریع را اشخاص ثالث اداره می‌کنند. نتیجهٔ موفق آزمایش فقط وضعیت همان لحظه را نشان می‌دهد و تضمینی برای امنیت، دسترس‌پذیری، حریم خصوصی، کیفیت تماس صوتی یا استریم نیست.
