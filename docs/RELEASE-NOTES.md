# DisRoute 0.3.0 — Windows preview

- Added VLESS, VMess, Trojan, and Shadowsocks share-link support.
- Added automatic protocol detection and clear inline feedback for unsupported links.
- Preserved encrypted profiles from 0.2.x through automatic field migration.
- Kept certificate verification mandatory and continued routing only Discord TCP/UDP traffic.
- Generalized the sing-box connection probe and status messages across supported protocols.
